# ![](https://user-images.githubusercontent.com/4441470/224455560-91ed3ee7-f510-4041-a8d2-3fc093025112.png) Soenneker.Grafana.OpenApiClient

Call Grafana's HTTP API through strongly typed request builders and models generated by Kiota from Grafana's OpenAPI description.

## Installation

```bash
dotnet add package Soenneker.Grafana.OpenApiClient
```

## Create a client

```csharp
using Microsoft.Kiota.Abstractions.Authentication;
using Microsoft.Kiota.Http.HttpClientLibrary;
using Soenneker.Grafana.OpenApiClient;
using System.Net.Http.Headers;

var httpClient = new HttpClient
{
    BaseAddress = new Uri("https://grafana.example.com/api")
};
httpClient.DefaultRequestHeaders.Authorization =
    new AuthenticationHeaderValue("Bearer", serviceAccountToken);

var adapter = new HttpClientRequestAdapter(
    new AnonymousAuthenticationProvider(),
    httpClient: httpClient);

var client = new GrafanaOpenApiClient(adapter);
```

The base URL must be the absolute Grafana API root, including `/api`. Generated request builders append endpoint paths such as `/folders` and `/dashboards`.

## Using the generated surface

The client follows Grafana's API hierarchy. For example, folder operations are available beneath `client.Folders`; endpoint methods accept request configuration and cancellation tokens.

Generated method names and models follow Grafana's source description and can change with it. Keep application-specific abstractions outside the generated namespace. Use `Soenneker.Grafana.OpenApiClientUtil` when you want application registration and managed client reuse.
